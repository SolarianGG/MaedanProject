# Game Idea
“Ants vs Insects” is a PvP Real Time Strategy game where players are playing as a 
commander of either Ants army or Insects army. Players start games with a certain number 
of workers and a main base. The main goal of each player is either to destroy all the 
opponent’s buildings or to make them leave by making unwinnable conditions using army 
units.
